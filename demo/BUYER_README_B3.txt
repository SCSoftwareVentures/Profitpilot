START HERE
1. Open ProfitPilot_Buyer_Demo.html with a browser that supports local HTML.
   On an iPhone, opening an HTML attachment may show its source or a preview
   instead of executing JavaScript. If that happens, use Safari through an
   appropriate trusted local-file workflow. The package does not promise
   automatic execution from ChatGPT, Files, or the GitHub website.
2. Read the orange synthetic-data warning. The records and reviewer
   identities in this demonstration are entirely fictional.
3. Inspect the withheld financial amounts. The invoice match and payroll
   allocation are not fully evidenced at the beginning.
4. Simulate the Riverside $500 invoice match. Full-period confirmed billed
   becomes $45,000.00, but contribution stays unavailable.
5. Simulate Northside's $600 payroll allocation. The fictional period now
   shows $31,300.00 delivery costs and $13,700.00 contribution.
6. Check that the $2,000.00 unapproved Harbour variation stays excluded.
7. Open "View the current synthetic evidence JSON on this device" to inspect
   the fictional source references and in-memory decision sequence.
   Select/copy the JSON text if your browser blocks the downloadable export.
8. Reset. Confirm the withheld amounts return and no state is persisted.
