# Managed jobs and readiness candidate

Migration 067 connects the existing commercial-cleaning Job Readiness Engine to a durable job history with exact contract/site assignment and approved baseline/date binding. An owner/admin with recent MFA records a synthetic job, evidence-backed check events, start, completion or cancellation. Every event is immutable and bounded; a database row lock serializes competing events. Status is derived from the event ledger, and the API independently evaluates the persisted checks through the existing shared readiness template, rejecting inconsistent output. All eleven required checks must be satisfied or explicitly permitted not-applicable before start; no edits to check history after start, no terminal-state reopening. A referenced evidence digest is an asserted review pointer and does not itself verify safety, scope, customer consent, actual delivery or profitability. Jobs do not change payroll or invoice totals. Contract site assignments now freeze while a live commercial baseline order is pending or approved, not only after recording a receipt. No roster, recurring scheduling, mobile field access, job changes, customer portal or external communication. Recovery inventory includes jobs and events. Production remains locked. Synthetic integration covers both readiness gate and lifecycle; browser device testing remains outstanding.
