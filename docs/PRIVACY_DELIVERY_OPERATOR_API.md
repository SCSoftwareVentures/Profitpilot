# Assisted privacy operator API (candidate only)

Migration 057 exposes exact preview, order status and explicit request/approve/reject/consume capabilities to active owner/admin identities with recent MFA. Database checks independently enforce tenant, case, order, scope, existing independent outcome, identity eligibility, distinct reviewer and one-time consumption. The API creates an append-only reservation bound to the work order; a generic approved work order cannot be substituted. All proofs bind the exact case and order, and previews are audited. All responses are no-store. The synthetic workbench accepts only UUIDs, recipient categories and opaque digests, never documents, credentials other than the existing synthetic access token, private keys or recipient addresses. Operators must share the independently checked candidate inputs through approved private custody, not through public repository or workbench result logs.

A release-authorized order is NOT evidence of transmission, receipt, redaction completeness, verified identity or legal compliance. No transport or receipt is implemented by this migration. Live release remains locked. Signed receipt reconciliation and externally approved secure transport/key custody are subsequent work. The new request ledger is included in signed recovery inventory; reissue inventories after migration. Do not use this as a production delivery gate.
